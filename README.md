# 🚀 Portfolio Website

> A premium single-page portfolio experience designed to showcase my journey across **frontend development, user experience design, and business intelligence**.

This project represents my personal brand through a modern, interactive, and visually immersive web experience.

Built with a **Liquid Glass inspired design system**, the website focuses on:

- Smooth animations
- Elegant layouts
- Interactive components
- Responsive experiences
- Performance optimization
- Modern frontend practices

The goal is not only to display information, but to create a memorable digital identity.
