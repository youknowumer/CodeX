How it works

Productive in four steps.

Set up your organization

Name the organization and create its administrator. You receive a one-time recovery code.

Add your people

The admin creates users with a role and department. Each gets a temporary password and a private workspace.

Run your day

Check in, start the timer, log events and raise cases from one top bar.

Make it yours

The admin sets the brand colour; every user adds their own look, density and text size.

Privacy & control

Private by design.

Vantage ESS is local-first. Your records live on your device, and you decide what moves.

  • Hashed passwords, locked doors. Passwords are salted and hashed (PBKDF2) and sign-in locks after repeated failures. No network calls unless you add an ERP connection.
  • Full portability. Export everything, including update history, as one JSON file.
  • Visibility controls. Hide your birthday, anniversary or mobile number in one switch.
  • Safe rendering. User input is escaped before it is displayed.
  • Optional PIN lock. Screen lock with auto-lock after inactivity.
  • Two-step reset. Erasing all data always asks twice.

FAQ

Good questions.

Is my data uploaded anywhere?

No. Records are saved in your browser or desktop app on this device. Use Export JSON to back up or move them.

Is the app pre-filled with sample data?

No. Every section starts empty, so every record you see is one you created.

How do updates work?

Replace the app with the new version and your data is kept. The Update centre records each update in a permanent history and shows what’s new. The desktop app can update itself from releases.

Can my whole company use it?

Yes. The administrator creates an account for each person, with a role and department, and everyone gets a private workspace on that device. Sharing one organization across many devices needs a server login, which is on the roadmap.

Is there documentation?

Yes. A searchable User Manual with 20 topics and keyboard shortcuts is built into the app.
